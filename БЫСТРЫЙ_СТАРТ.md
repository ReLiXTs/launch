## 📋 ЧТО ДЕЛАТЬ СЕЙЧАС:

### 🔴 ШАГ 1: Отключите защиту ветки main

Это **ОБЯЗАТЕЛЬНО**! Без этого push не сработает.

1. Откройте: https://github.com/ReLiXTs/launch/settings/branches
2. Найдите правило для ветки `main`
3. Нажмите **DELETE** (Удалить правило)
4. Подтвердите удаление

**ИЛИ** используйте GitHub Desktop (см. FIX_PUSH_PROBLEM.md)

---

### 🟢 ШАГ 2: Запустите push-to-github.bat

Откройте CMD (Win + R → `cmd` → Enter):

```cmd
cd C:\Users\Hoshino\Desktop\BRG
.\push-to-github.bat
```

Введите `y` и нажмите Enter.

При запросе логина/пароля:
- **Логин:** ваш GitHub username (ReLiXTs)
- **Пароль:** Personal Access Token (НЕ ваш пароль GitHub!)

---

### 🟡 ШАГ 3: Создайте новый Personal Access Token

Старый токен скомпрометирован! Создайте новый:

1. Откройте: https://github.com/settings/tokens
2. Нажмите **"Generate new token (classic)"**
3. Настройки:
   - **Note:** `Kamysh Launcher`
   - **Expiration:** `No expiration`
   - **Отметьте галочки:**
     - ✅ `repo` (Full control of private repositories)
     - ✅ `workflow` (Update GitHub Action workflows)
4. Нажмите **"Generate token"**
5. **СКОПИРУЙТЕ ТОКЕН** (например: `ghp_1234567890abcdef`)

---

### 🟢 ШАГ 4: Используйте токен для push

Когда `push-to-github.bat` спросит пароль:
- **Username:** `ReLiXTs` (или ваш username)
- **Password:** Вставьте скопированный токен (НЕ пароль GitHub!)

## 📂 АЛЬТЕРНАТИВА: GitHub Desktop

Если CMD не работает, используйте GitHub Desktop:

1. Скачайте: https://desktop.github.com/
2. Установите и войдите в аккаунт
3. File → Add Local Repository → выберите `C:\Users\Hoshino\Desktop\BRG`
4. Если ошибка "Not a Git repository":
   - Нажмите **"create a repository here"**
   - Name: `launch`
   - Нажмите **"Create Repository"**
5. Слева увидите файлы
6. Внизу напишите: `Initial commit`
7. Нажмите **"Commit to main"**
8. Нажмите **"Publish repository"**
9. Снимите галочку "Keep this code private"
10. Нажмите **"Publish Repository"**

## ✅ ПОСЛЕ УСПЕШНОГО PUSH:

1. Откройте: https://github.com/ReLiXTs/launch/actions
2. Дождитесь зелёной галочки (3-5 минут)
3. Нажмите на последний запуск
4. Прокрутите вниз до **Artifacts**
5. Скачайте `kamysh-launcher-msi`
6. Распакуйте ZIP → **У вас готовый .msi!** 🎉

## 🔄 ДОБАВЛЕНИЕ МОДОВ/КОНТЕНТА:

1. Поместите файлы в `server-data\`:
   ```
   server-data\
   ├── versions\          # Версии Minecraft
   ├── mods\              # Моды
   ├── resourcepacks\     # Ресурспаки
   ├── config\            # Конфигурации
   ├── shaderpacks\       # Шейдеры
   ├── saves\             # Миры
   └── datapacks\         # Датапаки
   ```

2. Синхронизируйте с GitHub:
   ```cmd
   .\sync-to-github.bat
   ```

3. GitHub Actions автоматически соберет новый .msi!

## ❓ ЧАСТЫЕ ПРОБЛЕМЫ:

### "remote rejected... push declined due to repository rule violations"
**Решение:** Отключите branch protection rules (см. ШАГ 1)

### "Authentication failed"
**Решение:** Используйте Personal Access Token вместо пароля

### "npm not found"
**Решение:** Установите Node.js: https://nodejs.org/

### "Git not found"
**Решение:** Установите Git: https://git-scm.com/
