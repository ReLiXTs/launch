## 📋 Шаги для запуска проекта

### 1️⃣ Загрузить проект на GitHub

**Запустите файл:** `setup-git.bat`

Этот скрипт автоматически:
- Инициализирует Git репозиторий
- Добавит все файлы
- Создаст первый коммит
- Запушит проект на GitHub

После выполнения скрипта **немедленно отзовите токен** в настройках GitHub!

Это откроет лаунчер в режиме разработки с открытыми DevTools.

### 3️⃣ Собрать .msi установщик

**Запустите файл:** `build-launcher.bat`

Установщик будет создан в папке `launcher\dist\`.

## 🎮 Как использовать лаунчер

### Для пользователей:

1. Запустите установщик из `launcher\dist\`
2. Установите лаунчер
3. Запустите лаунчер
4. Введите никнейм
5. Нажмите "Запустить Minecraft"

### Для добавления обновлений:

1. Добавьте файлы в папки `server-data\`:
   - `versions\` - версии Minecraft
   - `mods\` - моды
   - `resourcepacks\` - ресурспаки
   - `config\` - конфиги
   - `shaderpacks\` - шейдеры
   - `saves\` - миры
   - `datapacks\` - датапаки

2. Закоммитьте и запушьте:
   ```bash
   cd C:\Users\Hoshino\Desktop\BRG
   git add .
   git commit -m "Описание изменений"
   git push origin main
   ```

3. Лаунчер автоматически обнаружит обновления при следующем запуске

## 🔧 Автоматическая настройка ОЗУ

Лаунчер автоматически определяет оптимальное количество ОЗУ:
- **Формула**: 60% от общей памяти системы
- **Минимум**: 2 ГБ
- **Максимум**: 8 ГБ

Вы также можете:
- Вручную настроить ОЗУ в интерфейсе
- Нажать кнопку "Автонастройка" для пересчета
