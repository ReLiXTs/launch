## ❓ Решение проблем

### BAT файлы показывают непонятные символы
Все BAT файлы исправлены с `chcp 65001`. Если проблема есть:
1. Откройте CMD от имени администратора
2. Выполните: `chcp 65001`
3. Запустите BAT файл

### Git push не работает
1. Убедитесь что установлен Git: `git --version`
2. При первом push войдите через Git Credential Manager
3. Или установите GitHub CLI: `gh auth login`

### Лаунчер не запускается
1. Установите Node.js 18+ с официального сайта
2. Выполните `npm install` в папке launcher
3. Проверьте наличие Java 17+
