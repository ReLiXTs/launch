# 🌾 Камышечный Лаунчер

Лаунчер для Minecraft сервера "Камышечный" с автоматической загрузкой обновлений с GitHub.

## 📋 Возможности

- ✅ Автоматическая проверка и загрузка обновлений с GitHub
- ✅ Синхронизация модов, ресурспаков, конфигов, шейдеров, миров и датапаков
- ✅ Автоматическая настройка оптимального выделения ОЗУ
- ✅ Поддержка Fabric и Forge
- ✅ Красивый современный интерфейс
- ✅ Создание .msi установщика для Windows

## 🚀 Установка

### Из исходников

```bash
cd launcher
npm install
npm start
```

### Сборка .msi установщика

```bash
cd launcher
npm install
npm run build:win
```

Установщик будет создан в папке `dist/`.

## 📁 Структура проекта

```
launcher/           # Исходный код лаунчера
├── src/
│   ├── main.js          # Основной процесс Electron
│   ├── preload.js       # Мост между процессами
│   ├── updater.js       # Система обновлений
│   ├── minecraft.js     # Запуск Minecraft

├── resourcepacks/  # Ресурспаки
├── config/         # Конфигурации модов

```

## 🔄 Как добавить обновление

1. Добавьте файлы в соответствующие папки `server-data/`
2. Закоммитьте и запушьте изменения в GitHub
3. Лаунчер автоматически обнаружит обновления при следующем запуске или через 5 минут
4. Пользователи увидят уведомление и смогут обновиться одним кликом

### Пример: Добавление Fabric 1.21.1

```bash
# Поместите файлы в server-data/
server-data/
├── versions/
│   └── fabric-loader-1.21.1/
│       └── fabric-loader-1.21.1.jar
├── mods/
│   ├── optifine.jar
│   └── sodium.jar
├── config/
│   ├── sodium-options.json
│   └── ...
└── ...

# Коммитим
git add .
git commit -m "Добавлен Fabric 1.21.1 с модами"
git push origin main
```

## ⚙️ Настройка ОЗУ

Лаунчер автоматически определяет оптимальное количество ОЗУ:
- **Формула**: 60% от общей памяти системы
- **Минимум**: 2 ГБ
- **Максимум**: 8 ГБ или 80% от общей памяти

Вы также можете вручную настроить выделение ОЗУ в интерфейсе лаунчера.

## 🔧 Требования

- Windows 7/8/10/11 (64-bit)
- Java 17+ (для Minecraft 1.17+)
- Java 21+ (для Minecraft 1.20.5+)
- 4 ГБ ОЗУ минимум
