## ❓ РЕШЕНИЕ ПРОБЛЕМ

### BAT файлы показывают непонятные символы

**Решение:** Все BAT файлы уже исправлены с `chcp 65001`.

Если проблема есть:
1. Откройте CMD от имени администратора
2. Выполните: `chcp 65001`
3. Запустите BAT файл

### Git push не работает

**Решение 1: Git Credential Manager**
```bash
git config --global credential.helper manager
git push
```

**Решение 2: GitHub CLI**
```bash
winget install GitHub.cli
gh auth login
git push
```

### GitHub Actions падает

1. Откройте: https://github.com/ReLiXTs/launch/actions
2. Нажмите на упавший запуск
3. Посмотрите логи ошибки
4. Создайте issue: https://github.com/ReLiXTs/launch/issues
